# OpenCV Image Processing Toolkit

## Overview
OpenCV Image Processing Toolkit is a Python-based image processing application developed using OpenCV, NumPy, and Matplotlib.
The project allows users to perform various image enhancement and transformation operations through a menu-driven interface. 
It demonstrates fundamental and intermediate image processing techniques commonly used in computer vision applications.

## Features
### Basic Image Operations
* Grayscale Conversion
* Image Flipping
* Brightness Adjustment
* Gaussian Blur
* Edge Detection

### Advanced Image Operations
* Contrast Enhancement
* Image Rotation
* Image Sharpening
* Cartoon Effect
* Pencil Sketch Effect

### Image Analysis
* Histogram Visualization

### Additional Features
* Automatic Output Saving
* Organized Project Structure
* Multiple Processed Image Outputs

## Technologies Used
* Python
* OpenCV
* NumPy
* Matplotlib

## How to Run
### 1. Clone the Repository
```
git clone <repository-url>
```

### 2. Install Dependencies
```
pip install -r requirements.txt
```

### 3. Run the Application
```
python main.py
```

### 4. Choose an Operation
The application provides the following options:
1. Grayscale
2. Flip
3. Brightness
4. Blur
5. Edge Detection
6. Contrast
7. Rotate
8. Sharpen
9. Cartoon Effect
10. Pencil Sketch
11. Histogram Analysis
